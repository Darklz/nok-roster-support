NOK Payment Checker

อ่าน roster Merlot และดูประมาณการรายได้การบินบน iPhone, iPad และ Safari ที่รองรับส่วนขยาย · Internal use only

เริ่มใช้งาน

  1. ติดตั้งแอป เปิด Settings → Safari → Extensions (ตำแหน่งเมนูอาจต่างตามรุ่นระบบ)
  2. เปิด NOK Payment Checker และอนุญาต ddportal.merlot.aero รวมถึงบริการอัตราจ่าย Google Apps Script ที่ส่วนขยายร้องขอ
  3. ล็อกอิน Merlot ใน Safari ด้วยบัญชีที่มีสิทธิ์ แล้วเปิดเอกสาร roster ฉบับเต็มของคุณ
  4. เปิด NOK Payment Checker จากเมนูส่วนขยาย แล้วกด “อ่าน Roster” ระบบหา ID จาก Profile ที่ซ้ำมากที่สุด โดยไม่ต้องกรอก ID หรือรหัสเปิดใช้งาน
  5. ระบบส่ง ID ไปดึงเรทจาก Google Sheet ถ้ายังไม่มีเรท ให้ตรวจ ID ที่แสดง กรอกจำนวนเงินทั้ง 6 ช่อง แล้วกด “ส่งเรทลงชีตและคำนวณ” เพื่อส่งข้อมูลให้ผู้ดูแลจัดเก็บ จากนั้นระบบอ่านค่ากลับมาคำนวณ ต้องมีอินเทอร์เน็ต

ตัวชีตเป็นส่วนตัว แต่ API ไม่มีการยืนยันตัวตน ผู้ที่รู้ ID และ URL ของ API อาจเรียกดูเรทของ ID นั้นได้ อ่านรายละเอียดใน Privacy Policy ก่อนส่งข้อมูล

อัตราจ่ายและชั่วโมงมาตรฐาน

เงินเดือน เงินส่วนอื่น เรทสามขั้น และค่าเดินทางรายวันดึงจากแท็บ Rates ส่วนชั่วโมงมาตรฐานดึงจาก RouteHours ผู้ดูแลแก้ค่าหรือเพิ่มรูทได้ในชีต ขาไป–กลับแยกกันและห้ามรูทซ้ำ ชั่วโมงใช้รูปแบบชั่วโมง:นาที เช่น 1:25 ไม่ใช่ 125 หรือ 50:00 หากตั้งใจหมายถึงนาที

ค่าบินนับเลขเที่ยวบินใน operating flights ของ Profile ที่ตรงกับ ID ที่เลือก ใช้ชั่วโมงอ้างอิงรายเส้นทาง หากรูทขาดอ้างอิงจะใช้ชั่วโมงจริงรวมเวรแทนเฉพาะกรณีที่แยกเที่ยวที่นับได้อย่างถูกต้อง และแสดงสีแดง หากข้อมูลไม่พอ ยอดจะระบุว่ายังไม่ครบ

รายงานและสลิป DRAFT ONLY

แต่ละวันแสดง Flight / Transport / Lay Over และเรทที่ใช้ตามชั่วโมงสะสม คืนค้างนับวันที่มี <Accom> วันละหนึ่งครั้ง ไม่ถือว่าเวรข้ามเที่ยงคืนทุกเวรเป็นคืนค้าง ค่าค้างคืน 1,000 บาท/คืน รายได้อื่นของเดือนเริ่มที่ 0 อัตราภาษีหัก ณ ที่จ่ายปรับได้ เริ่มที่ 16% และประกันสังคมประมาณการ 875 บาท

สลิปแสดงยอด Gross และ Net โดยมี DRAFT ONLY กำกับ เป็นประมาณการ ไม่ใช่เอกสารที่นายจ้างออก ภาษีและประกันสังคมเป็นสมมติฐาน ไม่ใช่กฎจ่ายจริงที่ยืนยันแล้ว ข้อความ Expect Paid in End of ... เป็นการคาดการณ์สิ้นเดือนถัดจากเดือน roster รายได้อื่นเฉพาะเดือนและอัตราภาษีที่ปรับในรายงานใช้ในเครื่อง ไม่ส่งลงชีต และรีเซ็ตเมื่ออ่าน roster ใหม่

แก้ปัญหา

  • อ่าน roster ไม่ได้: ตรวจว่าเปิดเอกสารใน Safari และอนุญาตส่วนขยาย หลังอัปเดตแอปให้ปิดแท็บเอกสารแล้วเปิดใหม่
  • ตารางชั่วโมงไม่ถูกต้อง: ผู้ดูแลตรวจหัวคอลัมน์ route / blockTime ใน RouteHours รูทซ้ำ และเวลาที่ไม่อยู่ในรูปแบบ H:MM หรือเกิน 24:00
  • ดึงเรทไม่ได้: ตรวจอินเทอร์เน็ต สิทธิ์เข้าถึงบริการ Google และให้ผู้ดูแลตรวจรายการ ID กับสถานะ enabled
  • ต้องแก้หรือลบเรท: ติดต่อผู้ดูแลกลุ่มเป็นการส่วนตัว รายการเดิมแก้ในชีต การลบแอปไม่ลบรายการใน Google Sheet

English

Enable the Safari extension and allow the Merlot roster site and Google rate-service domains. Open your authorized roster and tap Read Roster. The extension automatically selects an employee ID and retrieves rates and standard route hours through Google Apps Script. Missing rates can be submitted with that ID to a private administrator-owned Google Sheet. The API has no authentication: anyone knowing an ID and its URL can retrieve rates. See the Privacy Policy before submitting. Calculations and draft payslips remain on-device; tax and social-security amounts are estimates. Contact your group administrator privately for changes or deletion of rate records.
