นโยบายนี้อธิบายรุ่นที่เชื่อม Google Sheets และ Google Apps Script เพื่ออ่านอัตราจ่ายตามรหัสพนักงานและชั่วโมงมาตรฐานรายเส้นทาง

ข้อมูลที่ส่งและจัดเก็บบน Google

เมื่อกดอ่าน roster ส่วนขยายจะอ่าน Employee ID จากเอกสารที่เปิดใน Safari แล้วส่งเฉพาะ ID ไปยัง Google Apps Script ของผู้ดูแล เพื่อรับเงินเดือน เงินส่วนอื่นประจำ เรทค่าชั่วโมงบินสามขั้น ค่าเดินทางรายวัน และตารางชั่วโมงมาตรฐาน RouteHours

หากยังไม่มีเรท แบบฟอร์มจะแสดง ID ที่อ่านได้และจำนวนเงิน 6 ช่อง เมื่อกด “ส่งเรทลงชีตและคำนวณ” ระบบจะส่ง ID และจำนวนเงินทั้ง 6 ค่าไปสร้างรายการใน Google Sheet แล้วอ่านค่าที่บันทึกกลับมาคำนวณ ผู้ดูแลอาจเป็นผู้กรอกหรือแก้ไขข้อมูลในชีตด้วย รายการประกอบด้วย ID เรท สถานะเปิดใช้งาน และป้าย/เวลาที่ปรับปรุง ข้อมูลเงินเดือนและเรทจึงเชื่อมโยงกับตัวบุคคลผ่าน Employee ID

การเข้าถึงข้อมูลและข้อจำกัด

แอปไม่มีล็อกอินหรือรหัสเปิดใช้งาน API เรียกดูเรทตาม Employee ID ได้โดยไม่ยืนยันตัวตน แม้ตัวไฟล์ Google Sheet จะตั้งเป็น Restricted ผู้ที่รู้ ID และ URL ของ API ก็อาจเรียกดูเงินเดือนและเรทของ ID นั้นได้ การอ่าน ID จาก roster ไม่ใช่การยืนยันว่าเป็นเจ้าของ ID และ Unlisted App ไม่ใช่มาตรการรักษาความลับ

API อนุญาตให้ส่งเรทครั้งแรกให้ ID ที่ยังไม่มีข้อมูล โดยไม่มีการอนุมัติจากผู้ดูแลก่อนใช้งาน แต่ไม่อนุญาตให้ส่งทับเรทที่มีอยู่แล้วผ่านแบบฟอร์ม การแก้ไขเรทเดิมทำในชีตโดยผู้ดูแล

ข้อมูลที่ประมวลผลในเครื่อง

เอกสาร roster ข้อความ Profile ชื่อลูกเรือ วันที่ เวร เลขเที่ยวบิน เส้นทาง และเวลาบินที่อ่านจากหน้าเว็บ ใช้ในหน่วยความจำของอุปกรณ์เฉพาะการอ่านครั้งนั้น ยกเว้น Employee ID ที่ส่งตามข้างต้น เราไม่อัปโหลดเอกสาร roster รายละเอียดเที่ยวบิน รหัสผ่านหรือคุกกี้ Merlot ไปยังบริการอัตราจ่าย รายได้อื่นเฉพาะเดือน อัตราภาษีที่ปรับในรายงาน ยอดคำนวณ และสลิป DRAFT ONLY ไม่ถูกส่งไปเก็บในชีต

วัตถุประสงค์และผู้ให้บริการ

ใช้ ID และข้อมูลรายได้เพื่อค้นหา/เก็บอัตราจ่ายและแสดงประมาณการรายได้ซึ่งเป็นการทำงานหลักของแอป ไม่มี SDK โฆษณาหรือ analytics ไม่มีการใช้ข้อมูลเพื่อโฆษณา การติดตามข้ามแอป/เว็บไซต์ หรือขายข้อมูล Google Sheets และ Apps Script ให้บริการพื้นที่จัดเก็บและ API ผ่าน HTTPS ภายใต้ นโยบายความเป็นส่วนตัวของ Google ผู้ให้บริการอาจประมวลผลข้อมูลการเชื่อมต่อและบันทึกระบบตามนโยบายของตน

ส่วนขยายต้องได้รับอนุญาตเข้าถึง ddportal.merlot.aero เพื่ออ่านเอกสารที่ผู้ใช้เปิด และ script.google.com / script.googleusercontent.com เพื่อเรียกบริการของ Google การล็อกอินและใช้งาน Merlot อยู่ภายใต้นโยบายของนายจ้างและผู้ให้บริการ Merlot บริการของ Apple และ GitHub มีนโยบายของตนเอง

ระยะเวลาเก็บ การแก้ไข และการลบข้อมูล

รายการ Employee ID และเรทในชีตจะคงอยู่จนผู้ดูแลแก้ไขหรือลบรายการ การปิด Extension หรือลบแอปไม่ได้ลบรายการใน Google Sheet หากต้องการตรวจสอบ แก้ไข ปิดใช้งาน หรือลบข้อมูล ให้ติดต่อผู้ดูแลกลุ่มที่ส่งลิงก์แอปให้คุณทางช่องทางส่วนตัวที่ใช้ติดต่อกัน การปิดสถานะใช้งานไม่เท่ากับการลบรายการ

รุ่นนี้ไม่บันทึก roster หรือเรทที่อ่านใหม่ลงที่เก็บถาวรในเครื่อง และการปรับค่าของเดือนใช้เฉพาะครั้งที่อ่าน รุ่นเก่าอาจเคยบันทึกข้อมูลไว้ในอุปกรณ์ จัดการข้อมูลเหล่านั้นผ่านการลบแอปหรือการตั้งค่าข้อมูล Safari ที่เกี่ยวข้อง การสำรองข้อมูลและ offload แอปขึ้นกับการตั้งค่าของ Apple

ติดต่อผู้พัฒนา

ปัญหาทั่วไปติดต่อ NOK Payment Checker Support ได้ แต่ GitHub Issues เป็นสาธารณะ อย่าโพสต์ ID เงินเดือน สลิป roster จริง รหัสผ่าน หรือข้อมูลส่วนบุคคล คำขอเกี่ยวกับรายการเรทส่วนบุคคลให้ส่งถึงผู้ดูแลกลุ่มเป็นการส่วนตัว

English

NOK Payment Checker sends the employee ID selected from the open Safari roster to the administrator's Google Apps Script service to retrieve salary, fixed allowance, three hourly rates, daily transportation rate and the standard route-hours table. If rates are missing, pressing the submission button sends that ID and the six pay amounts to a Google Sheet. Administrators can also maintain these records. Financial records, active status and revision metadata are linked to the employee ID and used only for app functionality.

No login or access code is required. The Sheet file is Restricted, but the API returns rates by ID without authentication. Anyone knowing an ID and the API URL can retrieve that employee's salary/rates or submit initial rates for an unused ID. Existing rates cannot be overwritten through the API. Neither roster-ID selection nor unlisted distribution verifies identity or protects pay confidentiality.

Other roster details, crew names, flights, Merlot passwords/cookies, monthly other-income adjustments, withholding percentage, calculation results and draft payslips are not uploaded to the rate service. Current roster/rate calculations stay in memory for the current reading. Older app versions may have retained local records.

The service uses Google Sheets and Apps Script over HTTPS. No advertising or analytics SDKs, cross-service tracking or sale of data are used. Google may process technical connection metadata under its own policies. Sheet records are retained until the administrator deletes them; uninstalling the app does not delete remote records. Contact the group administrator privately to access, correct, disable or delete your rate record. General support is available at the GitHub link above; never post personal or payroll information publicly.
